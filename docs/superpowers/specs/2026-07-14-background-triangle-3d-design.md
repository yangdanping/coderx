# 背景三角形 3D 原型设计

## 目标

将 `src/assets/img/bg.svg` 中的粉红色圆角三角形升级为具有轻微厚度、可缓慢改变旋转方向的 3D 装饰物，同时维持当前背景的视觉语言：半透明粉彩填充、同色细描边和覆盖其上的纸张颗粒。

第一阶段只迁移三角形，用它验证造型、材质、动画、性能和主题适配。其他圆形、方块与不规则图形继续由现有 SVG 渲染。

## 视觉定义

当前风格定义为“纸张颗粒质感的半透明粉彩几何”，带有轻微的 Memphis 抽象风格。3D 化后采用“半透明磨砂亚克力/树脂”表达，而不是写实玻璃、金属或高光塑料。

三角形是保留原平面轮廓的圆角薄三角棱柱，不是四面体：

- 正面轮廓继续使用原 SVG path，避免改变辨识度和构图。
- 几何厚度为 14 个 SVG viewBox 单位，约为原三角形高度的 14%。
- 挤出边缘使用 3 个单位的圆角，4 个 bevel 分段，避免出现尖锐的硬塑料边。
- 正反面基色为 `#f3b2ac`，透明度 `0.50`。
- 侧面使用略深的 `#e99289`，透明度 `0.58`，以柔和色差表现厚度。
- 轮廓使用 `#ee675c`，透明度 `0.80`，目标屏幕宽度为 1.5 CSS px。
- 表面高粗糙度、零金属度，不使用 transmission、环境贴图、投影或后期辉光。
- 使用低强度半球光和宽角度方向光，只制造足以辨认体积的柔和明暗。

纸张颗粒继续由现有 CSS 伪元素覆盖在三角形上方，不烘焙到 Three.js 材质中。这样所有背景图形仍共享同一种纹理，而不会让 3D 物体显得来自另一套视觉系统。

## 技术路线

采用 SVG 与 Three.js 混合渲染，不在外部 SVG 文件内部模拟三维投影，也不一次性重写全部背景。

```text
页面内容                         z >= 0
────────────────────────────────────
纸张颗粒（App.vue::after）        z = -1
3D 三角形（透明 WebGL Canvas）    z = -2
其余几何图形（bg.svg）            z = -3
HTML 主题底色                     最底层
```

选择混合路线的原因：

1. SVG 只有二维几何和二维变换。让三角形产生真实厚度、遮挡关系和任意轴旋转，需要在 JavaScript 中持续重新投影各个面，等同于自行实现一个简化渲染器。
2. `bg.svg` 当前作为 CSS `background-image` 加载，Vue 无法直接访问其内部 path；嵌入其中的脚本也不是可靠的应用运行方式。
3. 项目已经依赖 Three.js，无需增加生产依赖。
4. 只迁移一个图形便于对照原效果；如果原型不合适，可以恢复 SVG path，不影响其他背景元素。

未选择的替代方案：

- **纯 SVG 伪 3D：** 初始成本低，但只适合固定角度或少量关键帧，随机多轴旋转的几何和遮挡维护成本高。
- **全部改为 Three.js：** 最终可以统一光照和运动，但首轮范围过大，也更难判断是哪一个变量破坏了现有风格。

## 组件与职责

### `BackgroundTriangle3D.vue`

新增独立背景组件，由 `App.vue` 挂载，职责限定为：

- 创建透明 WebGL renderer、正交相机和三角形场景。
- 维护画布尺寸、主题滤镜、页面可见性和动画帧生命周期。
- WebGL 初始化成功后隐藏内置的二维 SVG fallback。
- 卸载时取消动画帧、移除监听器并 dispose renderer、几何体和材质。

组件设置 `aria-hidden="true"` 和 `pointer-events: none`；它是纯装饰层，不出现在可访问性树中，也不拦截页面交互。

### `triangle3d.ts`

将可独立测试的 Three.js 逻辑放入辅助模块：

- 根据原 SVG path 建立 `Shape` 和圆角挤出几何。
- 建立正反面、侧面和轮廓材质。
- 生成受约束的随机目标姿态。
- 根据 viewport 计算与 SVG `center / cover` 等价的正交相机视域。

轮廓从 `EdgesGeometry` 生成，并使用屏幕空间宽度的 line segments 渲染。阈值过滤掉正反面的三角剖分线和细碎 bevel 分段，只保留外轮廓与能表达厚度的主要折线。

### `App.vue` 与 `bg.svg`

- `App.vue` 在页面内容之前挂载 `BackgroundTriangle3D`。
- 原 `::before` SVG 背景层从 `z-index: -2` 下移到 `-3`。
- Three.js 组件位于 `-2`，并应用与 SVG 相同的 `var(--bg-filter)`，使深色主题下的亮度与饱和度变化一致。
- 纸张颗粒 `::after` 继续位于 `-1`。
- 原三角形 path 从 `bg.svg` 移除，避免 2D 与 3D 图形重叠。

## 坐标与响应式映射

Three.js 使用正交相机而不是透视相机。这样三角形旋转时具有三维厚度和面变化，但不会因透视产生明显的近大远小，整体仍接近原来的平面插画。

以 SVG 的 `1400 × 800` viewBox 作为场景基准：

1. renderer 使用 viewport 的 CSS 宽高。
2. 计算 `scale = max(viewportWidth / 1400, viewportHeight / 800)`，与 CSS `background-size: cover` 一致。
3. 相机可见宽高分别为 `viewportWidth / scale` 与 `viewportHeight / scale`。
4. 三角形沿用原 path 的中心坐标，并将 SVG 向下为正的 Y 轴转换为 Three.js 向上为正。

resize 时只更新 renderer 尺寸、线条材质 resolution 和相机视域，不重建几何体。device pixel ratio 上限设为 `1.5`，防止高分屏背景装饰消耗不必要的 GPU 填充率。

## 旋转行为

动画围绕三角形自身中心发生，第一阶段不增加平移漂浮，以便单独判断 3D 旋转是否自然。

- 每段动画持续时间从 18–28 秒中随机选择。
- X、Y 轴目标角度限制在 `-35°..35°`；每个目标至少有一个轴达到 `12°`，保证能看见厚度。
- Z 轴在当前角度基础上随机前进或后退 `35°..110°`，避免始终朝一个方向机械旋转。
- 使用 quaternion slerp 和 ease-in-out 插值在目标姿态之间连续过渡。
- 到达目标后立即生成下一个目标；角速度在连接点为零，不发生跳变或抖动。
- 不允许把 X 或 Y 旋转到接近 `90°`，避免三角形长时间侧面对着相机而视觉消失。

随机数只决定目标姿态和时长，不改变颜色、大小、位置或厚度。辅助函数允许注入随机数源，使自动化测试可以使用固定序列而不产生 flaky test。

## 降级与性能

- 组件初始渲染一个与原 path 一致的内联二维 SVG fallback；WebGL 首帧成功后再隐藏它，避免初始化闪空。
- WebGL 创建失败时保留 fallback，不抛出影响应用启动的错误。
- `prefers-reduced-motion: reduce` 下保留一个固定的浅角度 3D 姿态，但不启动持续动画。
- 页面进入后台时通过 `visibilitychange` 暂停渲染，重新可见时从当前姿态继续。
- 动画循环限制为最高 30 FPS；单一装饰物不启用阴影、后处理、环境贴图或多重采样 render target。
- Canvas 使用透明清屏，只渲染三角形，不绘制页面底色。

## 测试与验证

先增加失败测试，再实现功能。

### 自动化测试

1. `bg.svg` 不再包含粉红色三角形 path，其他几何图形仍存在。
2. 三角形辅助模块产生预期的 viewBox 边界、14 单位厚度和圆角挤出参数。
3. 固定随机数序列下，目标角度和时长始终落在约束范围内。
4. 相机映射在桌面、宽屏和移动端 viewport 下与 `background-size: cover` 的裁切结果一致。
5. 组件正确响应 resize、`visibilitychange` 和 reduced-motion，并在卸载时释放全部资源。
6. `App.vue` 的图层顺序保持 SVG、3D 三角形、纸张颗粒、页面内容。

### 视觉验证

在开发页面分别检查浅色和深色主题，并至少覆盖：

- `1400 × 800`：与 SVG 原始 viewBox 直接比较位置和初始尺寸。
- `1440 × 900`：检查 cover 裁切和桌面构图。
- `390 × 844`：检查移动端裁切、性能和是否遮挡主要内容。

验收标准：

- 初始近正面姿态与旧三角形的轮廓、位置、粉彩透明度和描边接近。
- 进入倾斜姿态后能清楚辨认轻微厚度，但没有强高光或写实玻璃感。
- 观察至少两个完整目标过渡时没有角度跳变、抖动或长时间侧面消失。
- 纸张颗粒同时覆盖 SVG 与 3D 三角形，深色主题下二者衰减一致。
- 背景不拦截点击、滚动、选择或键盘操作。
- 相关 Vitest、类型检查和生产构建通过。

## 非目标

- 本阶段不迁移圆形、方块或其他 SVG path。
- 不增加鼠标跟随、点击、拖拽或页面滚动视差。
- 不实现真实折射、景深、阴影、Bloom 或其他后处理。
- 不修改纸张颗粒资产、页面主题色或现有内容布局。
- 不以首次原型为由删除 Three.js 之外的现有背景实现；是否继续迁移其他图形由三角形验收结果决定。
