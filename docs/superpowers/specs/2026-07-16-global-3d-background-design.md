# 全局六形体 3D 背景设计

## 背景与目标

当前全局背景由 `src/assets/img/bg.svg` 提供六个带动画的二维装饰形体，现有圆角箭头由独立的 Three.js 组件渲染。本阶段把 SVG 中的六个形体升级为具有统一深度、双帽面轮廓和半透明软塑料材质的 3D 对象，同时保持页面原有颜色角色、视口锚点、边缘裁切和 Hero 视觉层级。

最终背景仍是纯装饰层：不可交互、对辅助技术隐藏，不改变页面内容、布局、导航或路由。

## 已批准的范围

范围只包含 `src/assets/img/bg.svg` 中的六个装饰形体：

1. 左上蓝色圆体。
2. 右下中性圆体。
3. 右侧大型绿色圆角体。
4. 顶部大型黄色拱形体。
5. 左下中性圆角胶囊体。
6. 底部绿色圆角方体。

明确不在范围内：

- `src/components/background/shape-3d/triangle/` 下现有箭头的源码、测试、视觉常量、运行时与运动。
- `src/components/canvas/retro-computer-shader/` 下页面专用的 WebGL 画布。
- 已完成但尚未挂载到全局背景的固定 `$` 字符模块。
- 页面内容安全区、导航层、纸张颗粒、字体、配色系统或路由的重设计。
- 把全部背景图形重构为通用场景框架。

## 视觉方向

现有箭头只作为只读视觉标尺。六个新对象采用已经批准的“双层轮廓软塑料”语言：

- 正反帽面都有轮廓线，轮廓之间不增加纵向深度连接线。
- 帽面与侧面使用略有差异的透明度，让深度可读但不形成高对比硬边。
- 材质高粗糙度、零金属度，不使用镜面金属、强发光或高亮玻璃效果。
- 蓝、黄、绿和中性色继续承担当前 `bg.svg` 的颜色角色，不统一改成单色。
- 小型边缘对象整体更透明、更安静；大型黄、绿对象负责提供缓慢的空间变化。
- 暗色主题通过现有 `--bg-filter` 与背景系统保持一致，不建立第二套暗色材质配置。

本模块独立持有材质值。默认基线为帽面透明度 `0.28`、侧面透明度 `0.26`、轮廓透明度 `0.42`、粗糙度 `0.95`、金属度 `0`；小型中性对象再应用较低的对象级透明度。数值与箭头形成同一视觉语言，但不得从箭头常量导入。

## 已比较的架构方案

### 方案 A：独立的六对象全局 Canvas（采用）

新增一个全局背景组件和一个 Three.js 运行时，六个对象共享同一个场景、相机、灯光与 renderer。现有箭头继续由自己的组件和 Canvas 渲染。

优势：不触碰已验收箭头；六个新对象只增加一个 WebGL 上下文；故障与回退边界清晰。代价：页面总计保留两个背景 Canvas，但比每个形体独立渲染更可控。

### 方案 B：把箭头合并到同一 Canvas（不采用）

能够减少一个 renderer，但必须改写箭头运行时、挂载边界和测试契约，与字节级保护要求冲突，也会让两个已经独立验收的功能互相影响。

### 方案 C：每个形体独立 Canvas（不采用）

单个对象隔离最强，但会增加六个 WebGL 上下文、六套监听器和动画循环，性能、同步和清理成本都过高。

## 模块边界

新增模块放在：

```text
src/components/background/shape-3d/global/
├── GlobalBackground3D.vue
├── global-background3d.ts
├── global-background3d-runtime.ts
└── test/
    ├── GlobalBackground3D.test.ts
    ├── global-background3d.test.ts
    └── global-background3d-runtime.test.ts
```

并在 `src/components/background/shape-3d/config/` 增加全局六形体的独立配置文件及配置契约测试。

各单元职责：

- `GlobalBackground3D.vue`：拥有 Canvas DOM、ready/failure 状态、主题滤镜和对 `App.vue` 的 readiness 通知。
- `global-background3d.ts`：拥有六个描述符、二维形状构造、挤出、双帽面边线、材质、姿态计算和 GPU 资源所有权。
- `global-background3d-runtime.ts`：拥有场景、正交相机、共享灯光、renderer、尺寸同步、动画时钟、可见性、减弱动态、失败通知和释放。
- `global-background3d.config.ts`：拥有本模块的颜色、深度、透明度、运动层级和性能阈值；不导入箭头视觉常量。
- `App.vue`：挂载新组件，并根据其 readiness 控制原 `bg.svg` 回退层的透明度。

不得提取新的 `shared/` 构建器，也不得让箭头导入新模块。新模块可以沿用已经验证过的组织方式，但必须拥有自己的配置和实现。

## 场景与数据流

初始化流程：

```text
App 保持 bg.svg 可见
  → GlobalBackground3D 挂载 Canvas
  → runtime 创建 renderer、scene、camera 和共享灯光
  → 根据六个描述符创建并加入六个对象
  → 设置尺寸与初始/减弱动态姿态
  → 首帧成功 render
  → runtime 通知组件 ready
  → 组件通知 App
  → Canvas 淡入，bg.svg 淡出
```

任一步在首帧成功前失败时，不发送 ready；`bg.svg` 保持完整可见。运行中发生 WebGL 上下文丢失时，runtime 停止循环、通知 unavailable 并释放仍可释放的资源，App 重新显示 `bg.svg`。本阶段不实现持续重试或恢复循环，SVG 已提供稳定且完整的会话级降级。

## 回退与层级

`src/assets/img/bg.svg` 保持字节级不变，继续是初始加载、WebGL 不可用、创建失败、首帧失败和上下文丢失时的精确回退。

全局负层级调整为：

| 层 | z-index | 行为 |
|---|---:|---|
| `App.vue::before` SVG 回退 | `-4` | 始终保留 DOM，仅在新场景 ready 后淡出 |
| 新六形体 Canvas | `-3` | ready 前透明，ready 后淡入 |
| 现有箭头组件 | `-2` | 保持文件和行为不变 |
| `App.vue::after` 纸张颗粒 | `-1` | 继续覆盖全部背景装饰 |

交叉淡化使用约 `300ms` 的 opacity transition。只有首帧成功完成后才能切换；renderer 创建成功不等同于 ready。失败切回 SVG 时使用同一短过渡，避免背景突然变空。

两个背景组件都保持 `pointer-events: none` 和 `aria-hidden="true"`。纸张颗粒、内容和交互层不参与 readiness。

## 几何与配置描述符

六个对象由类型化描述符驱动。每个描述符至少包含：稳定 ID、形状种类/几何参数、SVG 基准锚点、颜色角色、挤出深度、初始三轴姿态、对象级透明度和运动层级。

基准 ID 与颜色角色固定为：

| ID | 角色 | 基准颜色 |
|---|---|---|
| `blue-puck` | 左上小圆体 | `#1a73e8` |
| `neutral-puck` | 右下小圆体 | `#f1f3f4` |
| `green-slab` | 右侧大型圆角体 | `#bee0c6` |
| `yellow-arch` | 顶部大型拱形体 | `#fdd663` |
| `neutral-pill` | 左下中性胶囊体 | `#f1f3f4` |
| `green-cube` | 底部绿色圆角方体 | `#bee0c6` |

实现从 `bg.svg` 当前几何提取等价二维轮廓，并把 SVG 坐标映射为以画布中心为原点、Y 轴向上的世界坐标。几何在本地原点居中，再通过描述符放回原视口锚点。大型形体继续超出视口并被裁切，不能为了显示完整轮廓而内移。

每个对象使用一个挤出网格、帽面材质、侧面材质和一组胖线轮廓。轮廓位置只来自挤出几何最前与最后两个 Z 平面的边界边；任何线段的两个端点必须处在同一 Z 平面。

六个对象可共用不可变材质配置值，但每个对象仍明确拥有自己创建的几何、材质与线资源。对象的 `dispose()` 必须幂等地释放全部自有 GPU 资源一次。

## 相机、灯光与渲染

场景使用一台正交相机，以现有 `1400×800` SVG viewBox 为基准。相机初始朝向正对 XY 平面，六个对象通过自身姿态展示厚度，不使用透视相机制造额外的页面空间畸变。

所有对象共享一组克制的环境/半球光和一盏主方向光。灯光只负责区分帽面、侧面和深度，不投射实时阴影，不启用后处理、环境贴图、反射、泛光或物理透明排序特效。

renderer 配置：

- `alpha: true`、透明 clear color。
- `antialias: true`。
- `powerPreference: 'low-power'`。
- `outputColorSpace = SRGBColorSpace`。
- 宽屏 DPR 上限 `1.5`；窄屏 DPR 上限 `1.25`。
- Canvas CSS 尺寸始终等于视口，buffer 尺寸由 renderer 和 DPR 管理。
- 所有 `LineMaterial.resolution` 在初始化和 resize 时同步更新。

暗色主题不重建场景。Canvas 容器与现有 SVG、箭头一样使用 `filter: var(--bg-filter)` 和现有主题过渡，从而保持主题转换的一致时序。

## 运动层级

运动使用确定性的周期函数，不依赖每次加载的随机速度，便于视觉复现、测试和减弱动态静态姿态。

### 大型对象

- `yellow-arch`：约 `92s` 完成一次极慢三轴自旋。
- `green-slab`：约 `108s` 完成一次方向错开的极慢三轴自旋。
- 两者的世界锚点保持不变，不围绕页面或其他中心公转，不产生页面级横移。

### 小型对象

- 使用正弦/余弦组合在两个端点间缓慢踱步。
- 桌面位移总幅度按描述符限制在 `6–12px`，任何轴都不得越过描述符边界。
- 三轴倾斜限制在约 `±6°`，不得完成整圈旋转。
- 周期约 `15–24s`，对象之间错相，避免同步摆动。
- 中性小件使用更低对象级透明度；蓝圆和绿色方体也不得超过大型对象的视觉权重。

### 减弱动态与页面隐藏

`prefers-reduced-motion: reduce` 时停止动画循环，六个对象使用各自稳定、可读且能展示少量厚度的预设姿态，只在初始化或 resize 后渲染一次。

页面进入 hidden 状态时停止动画循环并记录暂停时刻；恢复时把隐藏时间从动画累计时间中扣除，因此对象不会突然跳到远处。取消减弱动态时从当前时刻建立新运动起点。

## 性能边界

- 新模块只创建一个 renderer、一个场景和一个动画循环。
- 视口宽度 `>= 768px` 时最多约 `30fps`，DPR 上限 `1.5`。
- 视口宽度 `< 768px` 时最多约 `24fps`，DPR 上限 `1.25`。
- 帧节流使用 runtime 自己的单调时钟，不依赖动画回调可能不同源的 timestamp。
- 页面隐藏或减弱动态时不保留活跃动画循环。
- 不启用实时阴影、后处理、纹理加载、环境贴图或每帧几何/材质分配。
- resize 只更新相机、renderer、线分辨率和响应式运动倍率，不重建几何。

## 响应式 framing

Canvas 与当前 `background: center / cover` 使用相同的 cover 规则：

```text
scale = max(viewportWidth / 1400, viewportHeight / 800)
visibleWorldWidth = viewportWidth / scale
visibleWorldHeight = viewportHeight / scale
```

正交相机左右、上下边界分别使用可见世界宽高的一半。对象世界锚点始终来自 `1400×800` 基准坐标，不为不同页面或断点维护第二套位置。

窄屏策略仅改变成本和微运动：

- `<768px` 时小型对象位移倍率为桌面的 `0.6`，倾斜倍率为 `0.75`。
- 大型黄、绿对象保持相同锚点和边缘裁切，不缩进内容区。
- 所有对象继续随 cover framing 被自然裁切；不保证完整露出。
- resize 在断点两侧都重新计算 DPR、帧率阈值和运动倍率，但保持当前运动相位连续。

## 错误处理与清理

组件捕获同步初始化错误，不向页面抛出阻断错误，也不隐藏 SVG。

runtime 的创建过程使用单一清理路径。任何创建或首帧错误都必须：

1. 停止 animation loop。
2. 移除 resize、visibility、reduced-motion 和 context-loss 监听器。
3. 释放已经创建的六对象资源。
4. 释放 renderer。
5. 通知组件保持/恢复 fallback。

`dispose()` 可重复调用且只执行一次。组件卸载后任何回调都不能再次更新 Vue 状态。WebGL 上下文丢失被视为运行期失败：停止本场景并恢复 SVG，不在后台无限重试。

## 测试策略

实现遵循 TDD，先写失败测试，再写最小实现。

### 描述符与几何

1. 精确存在六个稳定 ID，且颜色角色、尺寸类别、锚点和运动层级完整。
2. 六个形状均产生非空、有限且有非零面积/深度的几何。
3. 几何中心与描述符锚点分离，避免旋转时绕页面坐标公转。
4. 每个对象都有前后帽面轮廓。
5. 所有轮廓线段两端 Z 相同，证明没有深度连接线。
6. 帽面和侧面材质透明度不同，粗糙度为高值、金属度为零；配置来自本模块而非箭头。
7. 每个对象的资源都由幂等 `dispose()` 恰好释放一次；中途失败也释放已创建资源。

### 姿态与响应式

1. 两个大型对象位置在任意时间不变，但旋转连续变化且周期在设计范围内。
2. 四个小型对象的平移、倾斜和周期始终在描述符边界内，不出现完整旋转。
3. 窄屏位移与倾斜倍率分别为 `0.6` 和 `0.75`。
4. cover-frustum 在横屏、方形、平板竖屏和手机竖屏下与 SVG `center/cover` 数学一致。
5. 减弱动态返回确定的静态姿态且不随时间改变。

### 运行时与组件

1. 首帧成功后且仅在成功后通知 ready。
2. 宽屏使用 30fps / DPR 1.5 上限，窄屏使用 24fps / DPR 1.25 上限。
3. resize 更新相机、renderer 和全部线材质分辨率，不重建对象。
4. hidden 状态停止循环，恢复后不累计隐藏时间。
5. reduced-motion 初始化和动态切换都使用稳定姿态并停止循环。
6. 初始化失败、首帧失败和上下文丢失均恢复 fallback 并完整清理。
7. Vue 组件 ready 前保持 Canvas 透明；成功后触发交叉淡化；卸载时释放 runtime。
8. `App.vue` 保持 SVG、六形体、箭头和纸张颗粒的 `-4/-3/-2/-1` 顺序。
