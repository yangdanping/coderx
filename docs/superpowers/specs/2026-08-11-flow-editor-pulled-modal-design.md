# Flow 编辑器下拉弹窗设计

## 目标

将 Flow 页顶部内联展开的编辑器改为独立弹窗，同时保持现有绳子点击触发、下拉和回收的视觉语义。弹窗打开时绳子保持拉下状态；关闭时二者同步向上收回。

## 方案选择

采用原生 Vue `Teleport`、`Transition` 和现有 `editorOpen` 状态实现专用弹窗。

- 不使用 `el-dialog`：其居中弹窗和内置遮罩动画难以与绳子下拉轨迹严格同步。
- 不继续使用文档流内展开：会推挤 Feed，无法形成明确前后景层级。
- 专用模态层可以复用现有编辑器实例，精确控制层级、动效、焦点和关闭规则。

## 层级与视觉

从后到前分为三层：Flow 页面、全屏遮罩、弹窗与绳子。

- 遮罩使用主题相关的半透明色和轻微去饱和/模糊，提供清晰但不过重的前后景色差。
- 弹窗位于导航栏下方，宽度跟随 Flow 主列并限制在安全视口范围内。
- 弹窗使用较实的玻璃背景、细边框、圆角和柔和阴影，保证编辑区域可读。
- 绳子在打开态提升到模态层上方，并保持当前拉下位置。
- 右上角放置 16–18px 的细线关闭图标；默认低对比度，悬停或聚焦时才显示轻微圆形底色。

## 状态与动画

`editorOpen` 仍为唯一打开状态。

- 点击绳子打开：绳子和弹窗使用相同的 420ms 缓动向下进入，遮罩渐显。
- 打开完成：绳子保持拉下状态，弹窗保持前景位置。
- 点击绳子、右上角关闭图标或按 `Esc`：更新同一状态，弹窗与绳子同步向上退出，遮罩渐隐。
- 点击遮罩不关闭，避免误触中断编辑。
- 关闭时不销毁编辑器，草稿内容保留；重新打开可继续编辑。
- `prefers-reduced-motion` 下取消位移动画，仅保留即时状态切换。

## 可访问性与页面环境

- 弹窗使用 `role="dialog"`、`aria-modal="true"` 和可读的 `aria-label`。
- 打开时锁定页面滚动并将 Flow 背景内容设为不可交互。
- 打开后把焦点移入弹窗；关闭后把焦点还给绳子按钮。
- `Esc` 只在弹窗打开时拦截。
- 遮罩接收背景指针事件但不触发关闭；绳子和弹窗保持可交互。

## 组件边界

- `Flow.vue`：拥有编辑器草稿、模态结构、滚动锁定、键盘关闭和背景交互状态。
- `FlowCordWidget.vue`：保持点击切换逻辑，公开触发按钮聚焦能力，并根据打开态提升层级。
- `TiptapEditorFlow.vue`：不改编辑功能，只作为弹窗内容复用。

## 验证

- 组件测试覆盖绳子、`Esc`、关闭图标三种关闭方式，遮罩点击不关闭，关闭后草稿保留。
- 契约测试覆盖模态语义、层级和同步动画。
- 运行相关 Vitest、类型检查和生产构建。
- 在桌面和窄屏视口检查弹窗位置、绳子层级、色差与 reduced-motion 表现。
