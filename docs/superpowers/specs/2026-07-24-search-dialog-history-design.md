# 搜索弹窗与本地历史重构设计

## 目标

在保留现有搜索接口、完整搜索页和全局快捷键的前提下，将导航栏搜索弹窗改造成更紧凑的命令面板式交互：

- 降低弹窗尺寸与遮罩的视觉侵入感。
- 支持浅色和深色主题。
- 搜索请求期间在搜索图标与加载图标之间切换。
- 用独立的本地存储键维护搜索历史和收藏历史。
- 支持键盘选择搜索结果并打开文章。
- 不实现参考图中与本项目无关的业务子标题。

## 交互设计

### 打开与关闭

- 保留导航栏触发按钮和 `Command/Ctrl + K` 快捷键。
- 打开后聚焦搜索输入框并锁定背景滚动。
- `Escape`、点击遮罩或移动端关闭按钮关闭弹窗。
- 关闭后恢复背景交互和触发按钮焦点。

### 输入与结果

- 输入框左侧空闲时显示搜索图标，请求期间显示旋转加载图标。
- 输入非空时显示清除按钮。
- 搜索结果可通过鼠标或上下方向键选择。
- 按 Enter 时：
  - 存在高亮结果：打开该文章，并将文章标题和文章 ID 记录为带链接历史。
  - 没有高亮结果：记录当前关键词并进入 `/search?q=关键词` 完整搜索页。
- 点击搜索结果与 Enter 打开结果采用相同行为。

### 搜索历史

历史条目分为两种：

```ts
interface SearchHistoryItem {
  id: string;
  value: string;
  articleId?: string | number;
}
```

- 关键词历史没有 `articleId`，点击时只将关键词回显到输入框并触发建议搜索，不立即跳页。
- 文章历史带有 `articleId`，点击时直接进入文章详情页。
- 每条历史支持收藏切换和单独删除。
- 清空操作只清空普通历史，不影响收藏。

### 收藏

- 收藏使用与普通历史相同的数据结构。
- 收藏和取消收藏只修改收藏存储键。
- 删除普通历史不会连带删除收藏，避免误删。
- 收藏列表独立显示；没有收藏时不显示空白分区。

### 键盘提示

弹窗底部显示精简说明：

- `Enter`：打开或搜索。
- `↑` / `↓`：切换结果。
- `Esc`：关闭。

不显示与项目无关的 Algolia 品牌或供应商信息。

## 数据持久化

使用两个互相独立的 localStorage key：

- `coderx_search_history_v2`
- `coderx_favorite_search_history`

每组最多保存 20 条，最近使用或收藏的条目排在最前。通过稳定 ID 去重：

- 文章条目按 `articleId` 去重。
- 关键词条目按规范化后的关键词去重。

读取时验证缓存结构；无效数据回退为空数组。旧 `coderx_search_history` 字符串数组在首次读取时迁移为关键词条目，迁移成功后移除旧键。

## 组件边界

- `LocalCache` 负责缓存读写、验证、迁移、去重、数量限制和收藏切换。
- `NavBarSearch.vue` 负责弹窗显示、搜索请求、键盘状态、路由跳转和视图渲染。
- 不新增 Pinia store。历史仅供当前弹窗使用，引入全局响应式状态会增加不必要的同步复杂度。
- 不修改搜索 API 和完整搜索页的数据请求协议。

## 视觉设计

- 桌面端宽度约 640px，高度由内容决定，最大约 560px。
- 遮罩透明度和模糊程度低于现有实现。
- 移动端保留安全区、页面边距和圆角，不再强制占满整个视口。
- 列表项使用紧凑的单行布局，当前键盘项和 hover 项采用主题主色背景。
- 颜色基于现有 CSS 变量和 `color-mix()`，不硬编码仅适用于单一主题的面板颜色。
- 保留当前搜索触发 icon 的装饰性闪光动画，并尊重 `prefers-reduced-motion`。

## 错误与边界处理

- 空白输入不记录、不导航。
- 中文输入法组合期间不触发 Enter 行为。
- 请求失败时显示错误状态，历史与收藏仍可正常操作。
- 结果刷新后，高亮索引回到首项；没有结果时清除索引。
- 缓存 JSON 损坏或结构不正确时静默回退为空列表。
- 文章 ID 缺失的结果按关键词历史处理，不生成无效文章链接。

## 测试

单元测试覆盖：

- 新旧缓存结构迁移、两组 key 隔离、去重、数量限制和损坏数据回退。
- 点击关键词历史只回显输入。
- 点击文章历史直接进入详情页。
- 收藏切换和删除历史互不连带。
- 搜索与加载 icon 切换。
- 上下方向键循环选择结果。
- Enter 优先打开高亮文章，无高亮结果时进入完整搜索页。
- light/dark 使用主题变量的样式契约。
- 弹窗桌面和移动端尺寸契约、焦点恢复及 reduced-motion 行为。

## 分支整理

- 将当前搜索分支上的设计、现有 icon 动效和本次实现合并到 `main`。
- `codex/background-triangle-3d` 是从旧架构分出的实验分支；`main` 已在其后引入覆盖范围更广的全局 3D 背景实现。其代码不回灌到新架构。
- 验证 `main` 的构建与测试后移除旧 3D worktree，并删除除 `main` 外的本地分支。
- 不删除远端分支，因为请求仅明确了本地仓库分支整理，且当前远端只显示 `origin/main`。
