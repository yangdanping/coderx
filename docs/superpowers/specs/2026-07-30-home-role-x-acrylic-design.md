# 首页角色 X 静态亚克力立体材质设计

## 目标

把首页动态角色标题末尾的 X 渲染为与全局 3D 背景物体一致的“有描边、半透明、带厚度的亚克力塑料”，同时保留：

- `CoderX`、`WriterX`、`CreatorX`、`BuilderX` 的现有渐变色与 stop 位置。
- 标题扰动过程中目标字符格里的日文、符号等瞬时字符。
- 当前标题占位宽度、基线、响应式布局和屏幕阅读器标签。
- 可配置但始终静态的 3D 朝向与厚度方向。

材质不响应鼠标、触摸或设备方向。首页只展示配置给定的固定朝向。

## 方案

采用分层 SVG 亚克力字形。对当前字符同时绘制若干厚度层、正面和高光层；每层都使用当前扰动字符，因此任何瞬时字符都能同步获得相同材质。

该方案比 CSS 多重阴影更容易保持透明正面、渐变侧边和干净高光，也无需像 Three.js 字形那样在每次字符变化时重新生成挤出几何体。

## 组件边界

### `ScrambleFrameText.vue`

负责稳定字符格、扰动字符数据、外层可访问名称和静态朝向配置：

- `accentAcrylic?: boolean`：启用亚克力分层，默认 `false`。
- `accentTiltX?: number`：固定纵向倾角，默认 `-3`。
- `accentTiltY?: number`：固定横向倾角，默认 `6`。
- `accentDepthX?: number`、`accentDepthY?: number`：厚度延伸方向，默认均为 `5`。
- `accentGradientStartOffset?: string`：角色渐变起始 stop。

组件不注册 pointer 事件，不创建动画帧，不监听媒体查询，也不维护可变朝向状态。CSS transform 直接由静态 props 派生。

### `ScrambleAcrylicGlyph.vue`

仅负责视觉 SVG，接收当前字符、渐变 stop 和深度向量，输出：

1. 四个沿深度向量分布的半透明侧面层。
2. 低透明度渐变正面与清晰渐变描边。
3. 偏向左上方的半透明白色高光层。

所有内部 SVG 节点保持 `aria-hidden="true"`；外层 `ScrambleFrameText` 的 `aria-label` 是唯一朗读内容。渐变 ID 使用 `useId()` 保证实例隔离。

### `Home.vue`

- 可见标题和隐形宽度尺都启用 `accent-acrylic`。
- 两者使用相同的固定倾角与深度，确保占位几何一致。
- 四个角色继续映射既有渐变 start/end token，不创建新色板。

## 视觉约束

- SVG 使用与普通后缀一致的 `0 0 70 100` 字形坐标系，使正面基线和整体比例对齐正文。
- 默认朝向略向右、略向上，厚度向右下延伸，与背景亚克力物体的光照方向一致。
- 正面保持低透明度，背景网格和色彩可透过但不能完全消失。
- 描边继续使用当前角色渐变，视觉粗细约 1.5px。
- 厚度层透明度低于正面，避免堆叠成实心粗字。
- 高光仅增强左上边缘，不使用大面积模糊辉光。
- 不改变标题字体、字号、字符格宽度、右侧安全留白或扰动算法。

## 状态与数据流

`useWallHitScramble()` 继续输出当前 `frame` 和稳定 `target`。`ScrambleFrameText` 从 `frame` 取目标索引处的当前字符，并原样传给 `ScrambleAcrylicGlyph`。扰动帧和稳定 X 使用同一条渲染路径，没有第二套计时或字符状态。

朝向和深度完全由 props 决定；组件没有交互状态，也不会写入 store 或影响 Retro 屏幕文本。

## 性能与可访问性

- 每个亚克力字形固定渲染少量 SVG text 层。
- 不注册鼠标或触摸监听器，不调度 `requestAnimationFrame`。
- 不引入依赖，不创建 Canvas 或 WebGL context。
- 装饰 SVG 对辅助技术隐藏，稳定目标词通过外层 `aria-label` 暴露。

## 测试与验收

### 组件测试

- 默认消费者不渲染亚克力 SVG。
- 正面、厚度和高光层都显示当前扰动字符，而不是写死 X。
- 每个实例的所有渐变 ID 唯一。
- 静态倾角和深度 props 正确映射到 CSS 变量与 SVG 层。
- `ScrambleFrameText` 中不存在 pointer、媒体查询或动画帧运行时代码。

### 首页与浏览器验收

- 可见标题和隐形宽度尺使用相同静态配置。
- 四个角色精确复用现有 RGBA 色值和 stop 位置。
- 桌面与 390px 移动端均保持基线对齐，无横向溢出或裁切。
- 鼠标移动不会改变亚克力字形朝向。

## 非目标

- 不实现鼠标跟随、触摸跟随、设备方向控制或 360° 自由旋转。
- 不把标题 X 加入全局 Three.js 背景场景。
- 不修改背景物体、Retro 电脑或首页其它区块。
