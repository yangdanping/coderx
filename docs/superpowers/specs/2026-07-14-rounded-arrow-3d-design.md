# 3D 三角形改为圆角导航箭头设计

## 目标

在当前已验收的 3D 背景三角形基础上，将平面轮廓改为参考图中的圆角导航箭头：箭身具有明显内凹腰部，初始箭尖指向右上，正面为主且只露出少量厚度。同时进一步弱化描边，并暴露主体色与线框色常量，便于开发者在其他场景中复用和调整。

本次只改变轮廓、初始姿态和颜色入口。现有公转圆心、半径、方向、起点、周期、三轴自旋规则、物体厚度和页面图层关系保持不变。

## 视觉定义

新轮廓采用带明显内凹箭尾的导航指针，而不是普通凸三角形：

- 箭尖朝向右上，左侧形成较宽的短翼，下侧形成较长的箭柄。
- 箭尖、左侧外角、下侧外角和内凹转折均使用贝塞尔曲线圆滑连接。
- 平面轮廓本身包含圆角；挤出几何继续禁用 bevel，避免顶部凸起或额外高边。
- 轮廓包围尺寸和中心与当前三角形大致一致，避免改变背景构图和公转半径的视觉结果。
- 初始姿态以正面轮廓辨识度为优先，仅使用轻微 X/Y 倾斜露出侧面厚度；不依赖大幅 Z 旋转修正箭头朝向。
- 挤出总厚度继续为 `24` 个场景单位。

主体保持低饱和、半透明、磨砂亚克力质感。正面和侧面使用同一主体色，通过透明度与现有光照区分体积，不再为侧面维护单独的深色值。

描边仍为浅粉色，但从当前 `1.2px / 0.6 opacity` 调整为约 `1px / 0.42 opacity`。它需要在浅色背景上保留轮廓辨识度，同时不再成为物体最醒目的部分。

## 开发者颜色入口

在 `triangle3d.ts` 中导出两个只读常量：

```ts
export const TRIANGLE_BODY_COLOR = '#f8cbc6';
export const TRIANGLE_OUTLINE_COLOR = '#f7aaa3';
```

- `TRIANGLE_BODY_COLOR` 同时供正面材质、侧面材质和 SVG fallback 填充使用。
- `TRIANGLE_OUTLINE_COLOR` 同时供 Three.js 前后盖轮廓和 SVG fallback 描边使用。
- 透明度、粗糙度和线宽继续作为内部视觉参数，不扩大本轮公共配置面。

开发者修改这两个常量后，WebGL 和 fallback 的颜色必须同步变化，不需要在 Vue 模板中再修改硬编码色值。

## 实现边界

### `triangle3d.ts`

- 使用一组规范化的路径命令描述圆角箭头轮廓。
- 同一组路径命令用于创建 Three.js `Shape` 和生成 SVG fallback 的 `d` 属性，避免两个版本逐渐偏离。
- 正面与侧面材质读取 `TRIANGLE_BODY_COLOR`。
- 轮廓材质读取 `TRIANGLE_OUTLINE_COLOR`，并采用更轻的线宽和透明度。
- 调整 `STATIC_ROTATION`，使首帧近正面并只露出少量厚度。
- 不修改 `TRIANGLE_WORLD_POSITION`、`ORBIT_CENTER`、`ORBIT_OFFSET`、`ORBIT_DURATION_MS` 或 `calculateContinuousPose()` 的 position 计算。

### `BackgroundTriangle3D.vue`

- 从 `triangle3d.ts` 引用 fallback 路径、主体色和描边色。
- fallback 使用与 WebGL 相同的圆角箭头轮廓。
- fallback 的描边透明度与主实现保持同一弱化方向。
- 组件生命周期、画布层级和 WebGL 失败处理保持不变。

### 其他文件

`App.vue`、`bg.svg` 和运行时动画模块不需要行为修改。除非测试暴露同步问题，否则不触碰这些文件。

## 测试与验证

实现继续遵循先写失败测试再修改生产代码。

自动化测试覆盖：

1. 新几何保持约 `24` 单位厚度和与旧版相近的平面包围尺寸。
2. 轮廓具有足够的曲线分段，并包含内凹箭尾，而不是凸三角形。
3. 正面、侧面和 fallback 使用 `TRIANGLE_BODY_COLOR`；线框和 fallback 描边使用 `TRIANGLE_OUTLINE_COLOR`。
4. 线框宽度不大于 `1px`、透明度不大于 `0.45`。
5. SVG fallback 的路径与 Three.js 轮廓来自同一份路径命令。
6. 起点、25 秒公转位置和完整周期闭环的既有测试继续通过。
7. reduced-motion、页面隐藏暂停、资源释放和 WebGL fallback 的既有测试继续通过。

真实页面检查浅色和深色主题，并在每次刷新后的前两秒观察：

- 首帧箭尖清楚指向右上。
- 正面轮廓接近参考图，内凹腰部明显，圆角连续且没有局部凸起。
- 能看见少量侧面，从而保留 3D 体积，但侧面不压过正面。
- 描边比当前截图更轻，同时仍能从背景中辨认箭头边界。
- 自旋开始后轮廓没有异常折线、破面或轮廓穿插。

最终运行相关 Vitest、完整 Vitest、类型检查、相关 ESLint、生产构建和 `git diff --check`。

## 非目标

- 不修改公转轨迹、自旋速度、随机方向或动画帧率。
- 不恢复挤出 bevel，不增加阴影、辉光、折射或环境贴图。
- 不将其他 SVG 背景图形迁移为 Three.js。
- 不重命名现有组件目录或扩大为通用 3D 图形框架。
- 不把透明度、线宽、厚度和姿态全部暴露为公共配置；本轮只暴露主体色和线框色。
